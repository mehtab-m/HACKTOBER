# ChalkScript AI

Turn a photo of a hand-drawn website wireframe into an editable, interactive web preview, powered by Gemma 4.

This repository is being built up in stages through pull requests. The full project README arrives with the
final integration stage.

## Stages

1. Next.js template (`feature/nextjs-template`)
2. Landing page (`feature/landing-page`)
3. Remaining frontend (`feature/frontend`) and backend core (`feature/backend-core`), in parallel
4. Full backend (`feature/full-backend`)
5. Frontend/backend integration (`feature/frontend-backend-integration`)

Every stage lands on `main` through its own reviewed pull request.
